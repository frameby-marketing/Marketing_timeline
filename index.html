⚙ 구글 시트 연결 설정

하나의 구글 스프레드시트 안에 제품별 탭을 만들고 같은 스프레드시트 주소를 연결하세요. 탭 이름이 제품명과 같으면 자동으로 해당 탭을 불러옵니다.
PRODUCTS: []
💡 위 버튼은 지금 화면에만 적용됩니다. index.html 파일을 열어 상단 CONFIG.PRODUCTS 값을 위 코드로 바꿔 저장하면, 다음에 파일을 열 때도 자동으로 연결됩니다.
연결 방법 (제품 1개당)
  1. 구글 스프레드시트에는 종합, PH스탠드, 킥프레임, 맥세이프케이스, DW플러스, DW프로, 프레임팁 탭을 사용합니다.
  2. 각 탭의 컬럼은 카테고리, 항목, 구분, 상태, 시작일, 종료일, 담당자, 비고 순서로 유지하세요. 구분은 일회성·일별·주차별·월별·필요시를 사용하고, 상태는 안함·진행중·완료·재점검 필요·해당없음을 사용합니다. 진행률은 일회성만 계산하며 완료 + 해당없음을 처리 완료로 계산합니다.
  3. 그 탭이 선택된 상태에서 파일 → 공유 → 웹에 게시를 클릭하고, 게시할 대상에서 전체 문서가 아닌 해당 시트(탭)를 선택합니다.
  4. 형식을 쉼표로 구분된 값(.csv)으로 선택 후 게시를 누르고, 생성된 링크를 복사합니다.
  5. 위 목록에 제품명과 링크를 등록하고 이 설정 적용을 누릅니다. 제품마다 이 과정을 반복하세요.
